# سامانه جامع دبیران — نسخه نمایشی ۱

پروتوتایپ عملیاتی و راست‌به‌چپ پژوهشکده برای GitHub Pages.

## راه‌اندازی رایگان

۱. یک مخزن جدید **Public** در GitHub بسازید. (در صورت استفاده از GitHub Free برای Pages، معمولاً مخزن عمومی لازم است.)
۲. تمام فایل‌های این پوشه را بدون تغییر ساختار در ریشه مخزن آپلود کنید:

```
index.html
manifest.json
sw.js
icons/icon-192.png
icons/icon-512.png
icons/apple-touch-icon.png
```

۳. از بخش **Settings → Pages**، گزینه **Deploy from a branch**، سپس شاخه **main** و پوشه **/(root)** را انتخاب و Save کنید.
۴. آدرس سایت بعد از انتشار معمولاً این‌گونه خواهد بود:

`https://USERNAME.github.io/REPOSITORY/`

۵. سایت را روی Android با Chrome باز کنید و از منوی مرورگر **Install app / Add to Home screen** را انتخاب کنید. روی iPhone، در Safari از Share → Add to Home Screen استفاده کنید.

## قابلیت‌ها

- داشبورد مدیریتی، لیست و فیلتر پروژه‌ها
- فضای مستقل برای هر دبیرخانه
- شبیه‌ساز نقش‌های دبیر عالی، روابط عمومی، دبیر، معاون و عضو
- ثبت پروژه، تعیین مسئول و مهلت
- ثبت گزارش و لینک پیام تلگرام و بررسی گزارش
- تقویم فارسی و اعلان‌های درون سامانه
- برنامه ظرفیت هفتگی هر عضو و محاسبه جمع روزانه
- ذخیره تغییرات در localStorage همان مرورگر
- دانلود و بازیابی نسخه پشتیبان JSON
- طراحی واکنش‌گرا و PWA قابل نصب، و امکان استفاده آفلاین از رابط پس از اولین بارگذاری

## محدودیت مهم امنیتی و فنی

**این نسخه، پیش‌نمایش است؛ نباید با داده‌های محرمانه یا به‌عنوان سامانه مدیریتی چندکاربره واقعی استفاده شود.**

- انتخاب سمت، ورود امن نیست؛ تمام حساب‌ها نمایشی‌اند.
- مجوزهای نقش‌ها فقط در رابط نمایش داده شده و هنوز سیاست سروری ندارند.
- `localStorage` در دستگاه‌های دیگر همگام نمی‌شود.
- اعلان‌ها صرفاً داخل مرورگر ثبت می‌شوند. اعلان پوش سروری، ارسال خودکار تلگرام و ابلاغ قابل‌اثبات هنوز متصل نیستند.
- برای نسخه عملیاتی باید احراز هویت، سیاست Row Level Security در پایگاه داده و خدمت ارسال اعلان و ثبت سوابق اضافه شود.
- محاسبه ظرفیت آزاد فعلاً تقریبی است و ساعات تخمینی همه پروژه‌های باز را از ظرفیت هفتگی کم می‌کند؛ مدل‌سازی زمان‌بندی واقعی در نسخه بعدی انجام می‌شود.

برای نسخه چندکاربره، پیشنهاد فنی: Supabase Auth + PostgreSQL با RLS + backend امن برای اعلان‌های Web Push / Telegram Bot.
